## The target: one matrix

Everything downstream wants a single table: **genes in rows, samples in columns, one number per cell**, the fragments assigned to that gene in that sample. Salmon gives you {a.transcripts.toLocaleString("en-US")} transcripts per sample; for gene-level differential expression you need to sum the isoforms of each gene, for all samples, into one object. `tximport` does this.

## A transcript-to-gene table

You need a two-column table: transcript ID, gene ID. Make it from the GTF of the **same annotation release** you indexed:

```r
library(rtracklayer)
gtf <- import("ref/gencode.v47.annotation.gtf.gz")
tx <- gtf[gtf$type == "transcript"]
tx2gene <- data.frame(TXNAME = tx$transcript_id, GENEID = tx$gene_id)
write.csv(tx2gene, "ref/tx2gene.csv", row.names = FALSE)
head(tx2gene)
```


Alternatively, the `tximeta` package recognises the index you used (through its checksum) and fetches the matching annotation for you; it is a good choice when the index was built from a standard GENCODE or Ensembl release.

## Import

```r
library(tximport)
samples <- read.csv("samples.csv")
files <- file.path("quant", samples$run, "quant.sf")
names(files) <- samples$run
stopifnot(all(file.exists(files)))

tx2gene <- read.csv("ref/tx2gene.csv")
txi <- tximport(files, type = "salmon", tx2gene = tx2gene, ignoreTxVersion = TRUE)
names(txi)
```

```
[1] "abundance"           "counts"              "length"              "countsFromAbundance"
```

`txi$counts` is the gene-by-sample count matrix: transcript `NumReads` summed per gene. `txi$abundance` is TPM summed per gene. `txi$length` is, for each gene and each sample, the **average transcript length weighted by abundance**, and this is the piece a plain sum would miss.

`ignoreTxVersion = TRUE` strips the `.2` from `ENST00000456328.2` before matching, so a minor version difference between the FASTA and the GTF does not drop transcripts. If you see `transcripts missing from tx2gene`, the two files are from different releases; fix that rather than ignoring it.

## Why the length matrix matters

Suppose a gene has a long isoform and a short one, and treatment shifts usage from the long to the short one without changing the number of molecules. The short isoform yields fewer fragments per molecule, so the gene's count falls, and a naive analysis reports the gene as down-regulated. `tximport` passes the per-sample effective lengths to DESeq2 as an **offset**, so the model knows that the same count means more molecules when the transcripts are shorter. This correction is what makes the Salmon route statistically better than counting from alignments; it is why you should use `DESeqDataSetFromTximport` rather than extracting `txi$counts` and rounding it yourself.

## What a count is not

A count of 500 for gene A and 1,000 for gene B in the same sample does **not** mean B is expressed twice as much: longer genes produce more fragments. Counts are comparable **across samples for the same gene** (after normalization), which is all differential expression needs. For within-sample comparisons between genes, use `txi$abundance` (TPM). Never feed TPM to DESeq2.
